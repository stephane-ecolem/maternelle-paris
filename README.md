# maternelle.paris

Annuaire indépendant des écoles maternelles de Paris, édité par École M.
Astro, TypeScript et Tailwind, en génération statique, déployé sur Netlify à chaque push.

    npm install
    npm run dev      # développement
    npm test         # tests unitaires (tri, géométrie, shortlist, enrichissement)
    npm run check    # vérification des types
    npm run build    # site statique dans dist/

Données : voir `data/README.md`. Configuration en attente : `src/config.ts` et `.env.example`.
